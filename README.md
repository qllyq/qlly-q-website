## 宇宙動画について
今回の候補はPixabayの「Earth, space, spaceship」映像です。Pixabay上で無料利用可能と案内されている素材です。

動画ページ:
https://pixabay.com/videos/earth-space-spaceship-window-orbit-337746/

ダウンロードしたMP4を `space.mp4` という名前に変更し、`index.html` と同じ場所（リポジトリのルート）へアップロードしてください。

## GitHub Pages
`index.html` / `style.css` / `script.js` と画像ファイルをリポジトリのルートへ置いてください。
`space.mp4` は任意ですが、入れるとトップの窓に実際の宇宙映像が流れます。
